# LambdaX

LambdaX is an experimental adaptive serverless execution platform.

## Features (Planned)
- Function execution in isolated Docker containers
- Cold/warm behavior measurement
- Container pool management
- ML-based invocation demand prediction
- Function priority engine
- Adaptive scheduling and pre-warming
- SLA-bounded micro-queuing
- Cost-aware reclamation
